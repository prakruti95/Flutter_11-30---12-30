OOP -> Object Oriented Programming

Features of OOP

1)object : Any Entity which has own state and behaviour that is called an object
ex:pen,paper,chair etc..

2)class : Collection of objects that is called class
ex: human body

3)abstraction : Hiding internal details and showing functionalities
ex: login page

4)encapsualtion : Wrapping up of data or binding of data
ex: capsule

5)inheritance : When one object acquire all the properties and 
behaviour of parent class that is called an inheritance
ex: father-son

parent-child
super-sub
base-derived


6)polymorphism : Many ways to perform anything
ex:
1)method overloading
2)method overriding
